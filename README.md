## 🛠️ Installation

### English

1. Copy the `[EXEC]` folder and paste it directly into your main **God of War III** root folder.
2. Accept replacing the existing file when prompted.
3. Launch the game, go to **Options → Language**, and choose `Français` (you will see it in Arabic).
4. Enjoy the game in pure native Arabic!

### العربية

1. انسخ مجلد `[EXEC]` والصقه مباشرةً في المجلد الرئيسي للعبة **God of War III**.
2. اقبل استبدال الملف الموجود عند ظهور رسالة التأكيد.
3. شغّل اللعبة، ثم اذهب إلى **Options → Language**، واختر `Français` (ستراها بالعربية).
4. استمتع باللعبة بالعربية الأصلية الخالصة!
